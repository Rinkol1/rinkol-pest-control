RINKOL WEBSITE PACKAGE
======================

Files:
- index.html: website pages and content
- styles.css: responsive layout and brand styling
- script.js: mobile menu, quote-to-WhatsApp form, and scripted website assistant
- assets/: original logo extracted from the supplied Rinkol profile and generated visual crops

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP on your phone.
2. Open your GitHub repository.
3. Upload index.html, styles.css, script.js and the entire assets folder (including all files inside it) to the repository root.
4. Commit the files.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Wait for the Pages URL to appear.

IMPORTANT
- The assistant is a scripted website guide, not a connected generative AI model. A true AI assistant needs a secure server/API integration; do not put an AI API key in public website JavaScript.
- The enquiry form opens WhatsApp with the visitor's message pre-filled. The visitor must press Send in WhatsApp.
- Confirm company contact details, claims, service coverage, approvals and current product availability before publishing.
- The site does not process payments or store uploaded documents.
